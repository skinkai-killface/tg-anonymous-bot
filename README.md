# Telegram Anonymous Suggestion Bot

Telegram бот для анонимных сообщений (предложка) с модерацией в отдельном чате и публикацией в канал.

## Возможности
- 📩 **Все типы контента**: текст, фото, видео, альбомы (MediaGroup), стикеры, голосовые, кружочки, аудио, документы.
- 📸 **Поддержка альбомов**: пачки фото/видео объединяются в один цельный пост модерации и публикуются в канал единым альбомом.
- ⚖️ **Модерация с кнопками**:
  - `✅ Разрешить` — мгновенная или отложенная публикация в канал с анонимным заголовком.
  - `❌ Отказать` — отклонение предложения с уведомлением автора.
  - `✏️ Изменить текст` — редактирование текста/подписи перед публикацией через `/edit <текст>`.
  - `🚫 Заблокировать` — блокировка автора предложения.
- 💬 **Ответ пользователю в ЛС** прямо из чата модерации (через Reply).
- 🔗 **Кликабельная ссылка** на профиль автора в сообщении модерации.
- 🛡️ **Бесшумный бан через Middleware**: спам от заблокированных не грузит сервер.
- ⏳ **Anti-Flood**: ограничение 1 сообщение / 3 секунды от одного пользователя.
- 🚨 **Автобан спамеров**: при 4 попытках флуда за 10 секунд бот сам отправляет спамера в бан и уведомляет модераторов.
- 🔒 **Anti-Double-Click**: защита от дубликатов в канале при одновременном нажатии кнопок модераторами.
- 🗄️ **SQLite база данных (`aiosqlite`)**: надёжное асинхронное хранение, статистика и пользователи.
- 💾 **Бэкап базы данных (`/backup`)**: скачивание файла SQLite базы прямо в Telegram.
- 📢 **Рассылка (`/broadcast`)**: отправка сообщений всем пользователям бота с защитой от лимитов Telegram.
- ⏱ **Задержка публикаций (`/delay`)**: настройка интервала между автопубликациями в канал.
- 📊 **Статистика бота (`/stats`)**: общие счётчики и разбивка активности по модераторам.
- ⚡ **Автоматический `uvloop`** на Linux для максимальной скорости event loop.
- 🟢 **Уведомления о статусе**: алерты в чат модерации при запуске и остановке бота.
- 🔨 **Команды админов в чате модерации**:
  - `/help` — список всех доступных команд и подсказки.
  - `/ping` — проверка задержки и отклика бота.
  - `/stats` — статистика предложений, пользователей и модераторов.
  - `/backup` — скачать резервную копию базы данных SQLite.
  - `/broadcast <текст>` — рассылка объявления всем пользователям бота (или Reply на медиа).
  - `/delay [сек]` — настроить задержку автопубликаций в канал.
  - `/edit <текст>` — изменить текст предложки перед публикацией (ответом на сообщение).
  - `/restart` — перезагрузка процесса бота прямо из чата.
  - `/update` — автообновление: `git pull` + `pip install` + перезапуск прямо из чата.
  - `/ban <id>` — заблокировать пользователя по ID.
  - `/unban <id>` — разблокировать.
  - `/banlist` — показать список заблокированных.

## Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone https://github.com/skinkai-killface/tg-anonymous-bot.git
cd tg-anonymous-bot
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. Создайте файл `.env`:
```ini
BOT_TOKEN=your_telegram_bot_token
ADMIN_CHAT_ID=-100xxxxxxxxxx
CHANNEL_ID=-100xxxxxxxxxx
```

4. Запустите бота:
```bash
python bot.py
```

## Обновление на сервере

```bash
cd /path/to/tg-anonymous-bot
git pull
pip install -r requirements.txt  # если добавились новые зависимости
sudo systemctl restart tgbot
```

Или просто отправьте команду `/update` в чате модерации Telegram!
