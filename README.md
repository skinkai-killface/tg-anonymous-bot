# Telegram Anonymous Suggestion Bot

Telegram бот для анонимных сообщений (предложка) с модерацией в отдельном чате и публикацией в канал.

## Возможности
- 📩 Приём предложений от пользователей в ЛС (текст, фото, видео, документы).
- ⚖️ Пересылка в чат модераторов с кнопками:
  - `✅ Разрешить` — публикация в канал с заголовком «Новое анонимное сообщение».
  - `❌ Отказать` — отклонение предложения.
  - `🚫 Заблокировать` — блокировка пользователя.
- 💬 Ответ пользователю в ЛС прямо из чата модерации (через Reply).
- 🔗 Кликабельная ссылка на профиль автора в сообщении модерации.
- 🔨 Команды админов: `/ban <id>`, `/unban <id>`, `/banlist`.

## Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone <url_репозитория>
cd tg_bot
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```ini
BOT_TOKEN=your_telegram_bot_token
ADMIN_CHAT_ID=-100xxxxxxxxxx
CHANNEL_ID=-100xxxxxxxxxx
```

4. Запустите бота:
```bash
python bot.py
```
